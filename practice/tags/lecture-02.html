Problem #008

Tags: lecture-02, time complexity

What is the time complexity of the following function? State your answer using asymptotic notation (e.g., \(\Theta(n)\)).

def foo(n):
    for i in range(n):
        for j in range(n):
            for k in range(n**2):
                print(i + j + k)
Solution

\(\Theta(n^4)\). The loops are independent, so the print runs \(n \times n \times n^2 = n^4\) times.

Problem #010

Tags: lecture-02, time complexity

What is the time complexity of the following function?

def foo(n):
    for i in range(n**2 - 2*n + 100):
        j = 0
        while j < n:
            j += 1
Solution

\(\Theta(n^3)\). The outer loop runs \(n^2 - 2n + 100 = \Theta(n^2)\) times, and on each of its iterations the inner while loop runs \(n\) times, for a total of \(\Theta(n^2) \cdot \Theta(n) = \Theta(n^3)\).

Problem #011

Tags: lecture-02, time complexity

What is the time complexity of the following function?

def foo(n):
    total = 0
    for i in range(n**2):
        for j in range(n**2 + 5*n - 100):
            for k in range(n // 1_000_000):
                total += i**2 + n**2
    return total
Solution

\(\Theta(n^5)\). The three loops run \(n^2\), \(n^2 + 5n - 100 = \Theta(n^2)\), and \(\lfloor n / 1{,}000{,}000 \rfloor = \Theta(n)\) times, and the loop body takes constant time, so the total is \(\Theta(n^2 \cdot n^2 \cdot n) = \Theta(n^5)\).

Problem #012

Tags: lecture-02, time complexity

What is the time complexity of the following function?

import math

def foo(n):
    for i in range(math.floor(math.sqrt(n))):
        for j in range(math.floor(5*n**2 - math.sqrt(n)/1_000_000 + 100)):
            print(n * n)
Solution

\(\Theta(n^2 \sqrt n)\). The outer loop runs \(\lfloor \sqrt n \rfloor = \Theta(\sqrt n)\) times. The inner loop's range doesn't depend on \(i\), and \(5n^2 - \sqrt{n}/1{,}000{,}000 + 100 = \Theta(n^2)\), since the \(n^2\) term dominates. So the total is \(\Theta(\sqrt n) \times \Theta(n^2) = \Theta(n^2 \sqrt n)\).

Problem #013

Tags: lecture-02, time complexity

Express the time complexity of the following code using asymptotic notation in the simplest terms possible.

def foo(n):
    for i in range(n**3):
        for j in range(n):
            print(i + j)
        for j in range(n**2):
            print(i + j)
Solution

\(\Theta(n^5)\). The outer loop runs \(n^3\) times, and each iteration runs the two inner loops, which take \(n + n^2 = \Theta(n^2)\) time together. So the total is \(n^3 \times \Theta(n^2) = \Theta(n^5)\).

Problem #014

Tags: lecture-02, time complexity

What is the time complexity of the following function in terms of \(n\)? State your answer using asymptotic notation (e.g., \(\Theta(n)\)).

def foo(n):
    for i in range(n**3):
        for j in range(n):
            print(i + j)
    for k in range(n):
        for l in range(n**2):
            print(k * l)
Solution

\(\Theta(n^4)\). The two nested loops run one after the other, so we add their times. The first does \(n^3 \times n = n^4\) iterations and the second \(n \times n^2 = n^3\), so the total is \(n^4 + n^3 = \Theta(n^4)\).

Problem #015

Tags: lecture-02, time complexity

What is the time complexity of the following function in terms of \(n\)? State your answer using asymptotic notation (e.g., \(\Theta(n)\)) in the simplest terms possible.

import math
def foo(n):
    for i in range(3 * n**3 + 5 * n * math.ceil(math.log(n))):
        for j in range(math.floor(math.sqrt(n))):
            print(i + j)
        for k in range(n**2):
            print(k * i)
Solution

\(\Theta(n^5)\). The outer loop runs \(3n^3 + 5n\lceil \log n \rceil = \Theta(n^3)\) times. Each iteration runs the two inner loops, which take \(\lfloor \sqrt n \rfloor + n^2 = \Theta(n^2)\) time together. So the total is \(\Theta(n^3) \times \Theta(n^2) = \Theta(n^5)\).

Problem #016

Tags: lecture-02, time complexity

What is the time complexity of the following function?

def foo(n):
    while n > 1:
        n /= 10
        print(n)
Solution

\(\Theta(\log n)\). After \(k\) iterations, the value of n is \(n / 10^k\). The loop stops once this is at most 1, which happens after about \(\log_{10} n = \Theta(\log n)\) iterations.

Problem #017

What is the time complexity of the following function? State your answer as a function of \(n\) using asymptotic notation in the simplest form possible. (e.g., \(\Theta(n)\))

import math

def boo(n):
    i = n
    while i > 1:
        i = i / 2
        for j in range(1_000_000):
            print(i + j)
Solution

\(\Theta(\log n)\). Each iteration of the while loop halves \(i\), so it runs \(\Theta(\log n)\) times before \(i\) drops to 1 or below. The inner loop runs \(1{,}000{,}000\) times no matter what \(n\) is, so it's \(\Theta(1)\), and the total is \(\Theta(\log n)\).

Problem #018

Tags: lecture-02, time complexity

Express the time complexity of the following code using asymptotic notation in the simplest terms possible.

import math

def foo(arr):
    """`arr` is an array with n elements."""
    n = len(arr)
    ix = 1
    s = 0

    while ix < n:
        s = s + arr[ix]
        ix = ix * 5 + 2

    return s
Solution

\(\Theta(\log n)\). The index ix is multiplied by 5 (plus 2) on each iteration, so after \(k\) iterations it is at least \(5^k\). The loop stops once ix reaches \(n\), which takes \(\Theta(\log_5 n) = \Theta(\log n)\) iterations, each doing constant work.

Problem #021

What is the time complexity of the following function in terms of \(n\)?

from math import sqrt, log, ceil

def foo(n):
    for i in range(ceil(n**3 - 10*n + sqrt(n))):
        for j in range(ceil(log(n**2))):
            print(i, j)

Problem #022

Tags: lecture-02, time complexity

What is the time complexity of the following function in terms of \(n\)? State your answer using asymptotic notation (e.g., \(\Theta(n)\)).

def foo(n):
    i = 0
    while i < n**2:
        i = i + 2
        j = 0
        while j < n:
            for k in range(n):
                print(i + j + k)
            j = j + 10
Solution

\(\Theta(n^4)\). The outer loop increases \(i\) by 2 until it reaches \(n^2\), so it runs \(n^2/2\) times. The middle loop increases \(j\) by 10 until it reaches \(n\), so it runs about \(n/10\) times, and the innermost loop runs \(n\) times. The total is about \(\frac{n^2}{2} \cdot \frac{n}{10} \cdot n = \Theta(n^4)\).

Problem #023

Tags: lecture-02, time complexity

What is the time complexity of the following function in terms of \(n\)? State your answer using asymptotic notation (e.g., \(\Theta(n)\)) in the simplest terms possible.

def foo(n):
    for i in range(n):
        for j in range(2023):
            for k in range(n - i):
                print("DSC40B")
Solution

\(\Theta(n^2)\). For a fixed \(i\), the middle loop runs 2023 times (a constant) and the innermost loop runs \(n - i\) times. Summing over \(i\), the print runs \(2023 \sum_{i=0}^{n-1} (n - i) = 2023 \cdot \frac{n(n+1)}{2} = \Theta(n^2)\) times.

Problem #024

Tags: lecture-02, time complexity

Express the time complexity of the following code using asymptotic notation in the simplest terms possible.

def foo(n):
    for i in range(n):
        for j in range(i):
            for k in range(n):
                print(i + j + k)
Solution

\(\Theta(n^3)\). For a fixed \(i\), the middle loop runs \(i\) times and the innermost loop runs \(n\) times for each, so the print runs \(i \cdot n\) times. Summing over \(i\) gives \(n \sum_{i=0}^{n-1} i = n \cdot \frac{n(n-1)}{2} = \Theta(n^3)\).

Problem #025

def foo(n):
    for i in range(n):
        for j in range(n):
            for k in range(j): # ← notice the range!

Problem #026

Tags: lecture-02, time complexity

What is the time complexity of the following function?

def foo(n):
    i = 0
    while i < n:
        j = 0
        while j < i:
            print(i + j)
            j += 1
        i += 5
Solution

\(\Theta(n^2)\). The outer loop takes \(i = 0, 5, 10, \ldots\), about \(n/5\) values, and for each the inner loop runs \(i\) times. Writing \(i = 5k\), the total is \(\sum_{k=0}^{n/5} 5k = 5 \cdot \Theta\bigl((n/5)^2\bigr) = \Theta(n^2)\).

Problem #027

Tags: lecture-02, time complexity

Express the time complexity of the following code using asymptotic notation in the simplest terms possible.

def foo(n):
    for i in range(200, n):
        for j in range(i, 2*i + n**2):
            print(i + j)
Solution

\(\Theta(n^3)\). For a fixed \(i\), the inner loop runs \((2i + n^2) - i = i + n^2\) times. Since \(i < n\), this is \(\Theta(n^2)\), and the outer loop runs \(n - 200 = \Theta(n)\) times, so the total is \(\Theta(n) \times \Theta(n^2) = \Theta(n^3)\).

Problem #028

Tags: lecture-02, time complexity

What is the time complexity of the following function? State your answer as a function of \(n\) using asymptotic notation in the simplest form possible. (e.g., \(\Theta(n)\))

def boo(n):
    for i in range(200, n):
        for j in range(i, i * n):
            print(i + j)
Solution

If you count the number of times the inner loop body executes, you'll get something like \(n + 2n + 3n + \ldots + n\times n\). Factoring out the \(n\) and using the formula for the sum of the first \(n\) integers, we get \(n (1 + 2 + 3 + \ldots + n) = n \Theta(n^2) = \Theta(n^3)\).

Problem #029

Tags: lecture-02, time complexity

What is the time complexity of the following function in terms of \(n\)?

import math

def foo(n):
    for i in range(math.floor(math.sqrt(n))):
        for j in range(i):
            print(i + j)
Solution

\(\Theta(n)\). The outer loop runs \(\lfloor \sqrt n \rfloor\) times, and the inner loop runs \(i\) times. So the total is \(\sum_{i=0}^{\lfloor\sqrt n\rfloor - 1} i \approx \frac{(\sqrt n)^2}{2} = \frac{n}{2} = \Theta(n)\).

Problem #030 🌶️

Tags: lecture-02, time complexity

What is the time complexity of the following function in terms of \(n\)?

def foo(n):
    for i in range(n**2):

        for j in range(i):
            print(i+j)

        for k in range(n):
            print(i+k)

        for x in range(n - i):
            print(x)
Solution

\(\Theta(n^4)\).

Each iteration of the outer loop runs three inner loops one after the other, so we can count each inner loop's total work separately and add them up. The outer loop runs for \(i = 0, 1, \ldots, n^2 - 1\).

The first inner loop runs \(i\) times, so over all iterations of the outer loop it runs \(\sum_{i=0}^{n^2-1} i = \frac{n^2(n^2-1)}{2} = \Theta(n^4)\) times. The second inner loop runs \(n\) times for each of the \(n^2\) values of \(i\), for \(\Theta(n^3)\) in total. The third is the tricky one: range(n - i) is empty once \(i \geq n\), so it only runs for the first \(n\) values of \(i\), at most \(n\) times each, for \(O(n^2)\) in total. (The outer loop itself also does \(\Theta(n^2)\) work.)

Adding these up, the total is \(\Theta(n^4) + \Theta(n^3) + O(n^2) = \Theta(n^4)\); the first inner loop dominates.
